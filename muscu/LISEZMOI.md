# Ma Muscu

Appli web perso de suivi de musculation (fonctionne hors ligne, installable sur iPhone).

- Programmes : création manuelle (semaines → séances → exercices) ou import PDF / texte collé
- Séance : perf précédente sur chaque série, charge proposée automatiquement, minuteur de récup lancé à chaque série validée
- Progrès : records, 1RM estimé, courbe, historique, export CSV
- Sauvegarde : Réglages → Exporter (fichier .json)

En ligne : https://aurelien124.github.io/mon-scan/muscu/
Puis dans Safari : Partager → Sur l'écran d'accueil.
